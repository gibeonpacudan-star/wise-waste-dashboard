About This Project

Understanding the Solid Waste Forecast & Analytics Platform

Project Overview

This dashboard is an example web application that demonstrates forecasting and analysis of solid waste generation across barangays (local communities). It provides interactive visualizations for waste volume predictions, seasonal patterns, comparative analysis, and anomaly detection.

The original concept is inspired by Power BI-style analytical dashboards used by local government units and environmental agencies to plan waste collection, recycling programs, and landfill capacity.

Key Objectives

1. Prediction Data — Forecast total solid waste and breakdown by waste type (Biodegradable, Recyclable, Residual, Special, etc.) for the next month and full year. Track forecast error, accuracy, and trend direction (Rising / Falling).

2. Seasonality Data — Analyze monthly seasonality indices, identify peak waste months, average monthly waste, and highest-generating barangays and waste types.

3. Compare Barangay — Compare 2025 historical totals against 2026 predicted totals per barangay. Visualize monthly waste trends across years.

4. Anomaly Detector — Detect unusual deviations from expected monthly waste levels. Review yearly and monthly status, deviation percentages, and flagged anomalies.

Waste Types Tracked

  • Biodegradable
  • Recyclable
  • Recyclable / Residual
  • Residual
  • Residual / Biodegradable
  • Special

Technology

This example website is built entirely with HTML, CSS, and JavaScript. Charts are rendered using Chart.js. Data is sourced from the cleaned All Data sheet of the municipal waste records.

Disclaimer

This is a front-end demonstration only. No real forecasting models or live data connections are implemented. Numbers, trends, and anomaly flags are static examples designed to match the look and feel of a professional analytics dashboard.
